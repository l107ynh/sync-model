# F-008: GitLab MR 自動建立

## Status: active
## Sprint: 3
## Priority: P0

## 使用者故事
As a PM, I want 系統自動將設定變更推送到 GitLab cdk8s repo 並建立 MR, so that RD 只需要 review 和 merge，不需要手動修改程式碼。

## 範圍
- 使用 GitLab API 建立 branch
- 提交 codegen 產生的檔案變更
- 建立 Merge Request
- 追蹤 MR 狀態
- MR 描述包含變更摘要

## API Contract

### `POST /api/v1/merge-requests`
Auth: 無

Request Body:
| Field | Type | Required | Constraints |
|-------|------|----------|-------------|
| codegen_id | uuid | yes | 從 F-007 codegen/generate 取得 |
| title | string | no | max 200 chars, 預設自動產生 |
| description | string | no | max 5000 chars, 預設自動產生 |
| created_by | string | yes | max 100 chars |

Request Example:
```json
{
  "codegen_id": "uuid",
  "title": "chore: update asr-general replica in pro edition",
  "created_by": "lynn.yang"
}
```

Response 201:
```json
{
  "id": "uuid",
  "gitlab_mr_id": 123,
  "gitlab_mr_url": "https://gitlab.corp.ailabs.tw/yating/fedgpt/deploy/cdk8s/-/merge_requests/123",
  "source_branch": "sync-model/2026-04-02-abc123",
  "target_branch": "main",
  "status": "OPEN",
  "title": "chore: update asr-general replica in pro edition",
  "created_by": "lynn.yang",
  "created_at": "ISO 8601"
}
```

Error Responses:
| Status | Code | Condition |
|--------|------|-----------|
| 400 | INVALID_INPUT | codegen_id 缺失或 created_by 缺失 |
| 404 | NOT_FOUND | codegen_id 不存在 |
| 409 | DUPLICATE | 該 codegen_id 已經建立過 MR |
| 502 | GITLAB_ERROR | GitLab API 呼叫失敗 |

### `GET /api/v1/merge-requests`
Auth: 無

Query Parameters:
| Param | Type | Required | Default | Constraints |
|-------|------|----------|---------|-------------|
| status | string | no | - | PENDING, OPEN, MERGED, CLOSED |
| created_by | string | no | - | 篩選操作者 |
| page | integer | no | 1 | >= 1 |
| per_page | integer | no | 20 | 1-100 |

Response 200:
```json
{
  "data": [
    {
      "id": "uuid",
      "gitlab_mr_id": 123,
      "gitlab_mr_url": "https://gitlab.corp.ailabs.tw/...",
      "source_branch": "sync-model/2026-04-02-abc123",
      "target_branch": "main",
      "status": "OPEN",
      "title": "chore: update asr-general replica",
      "created_by": "lynn.yang",
      "created_at": "ISO 8601",
      "updated_at": "ISO 8601"
    }
  ],
  "pagination": { ... }
}
```

### `GET /api/v1/merge-requests/:mrId`
Auth: 無

Response 200: 同上單一 MR 物件，額外包含:
```json
{
  ...
  "change_history_ids": ["uuid-1", "uuid-2"],
  "files_changed": [
    {
      "path": "src/components/inferno/gpu/pro.ts",
      "action": "modify"
    }
  ]
}
```

### `POST /api/v1/merge-requests/:mrId/sync-status`
Auth: 無

用途: 從 GitLab 同步 MR 最新狀態（opened/merged/closed）

Response 200:
```json
{
  "id": "uuid",
  "status": "MERGED",
  "synced_at": "ISO 8601"
}
```

## GitLab 操作流程
1. 建立新 branch: `sync-model/{date}-{short-hash}`（從 main 分出）
2. 將 codegen 產生的檔案 commit 到新 branch
3. 建立 MR: source = 新 branch, target = main
4. MR description 自動包含:
   - 變更摘要（哪些 model / edition / env 被修改）
   - 變更明細表格
   - "Created by Sync Model GP" 標記

## MR Description 自動產生格式
```markdown
## Sync Model GP - 自動產生的設定變更

**操作者**: lynn.yang
**時間**: 2026-04-02 10:30 UTC

### 變更摘要
| Model | Edition | 變更 |
|-------|---------|------|
| asr-general | pro | replica: 2 -> 3 |
| llm-main | pro | deploy: false -> true |

### 變更原因
增加 prod 副本數以應對流量

---
*This MR was auto-generated by [Sync Model GP]*
```

## Business Rules
1. 同一個 codegen_id 只能建立一次 MR（防止重複）
2. Branch 名稱格式: `sync-model/{YYYY-MM-DD}-{6位隨機hash}`
3. Target branch 固定為 main
4. MR 建立後狀態為 OPEN
5. 系統不自動 merge，等待 RD review
6. GitLab token 從環境變數 `GITLAB_TOKEN` 讀取
7. GitLab project ID 從環境變數 `GITLAB_PROJECT_ID` 讀取

## Scenarios

### Happy Path

#### Scenario: 建立 MR 成功
GIVEN codegen #1 已產生，包含 pro.ts 的修改
WHEN POST /api/v1/merge-requests with { "codegen_id": "#1", "created_by": "lynn.yang" }
THEN response status = 201
AND gitlab_mr_url 不為空
AND status = "OPEN"
AND GitLab 上存在新的 MR

#### Scenario: 自動產生 MR title
GIVEN codegen #1 修改了 asr-general 的 replica
WHEN POST /api/v1/merge-requests with { "codegen_id": "#1", "created_by": "lynn.yang" }（未指定 title）
THEN MR title 自動產生，例如 "chore(sync-model): update asr-general settings"

#### Scenario: 查看 MR 清單
GIVEN 系統中有 3 個 MR（2 OPEN, 1 MERGED）
WHEN GET /api/v1/merge-requests?status=OPEN
THEN response status = 200
AND data 包含 2 筆

#### Scenario: 同步 MR 狀態
GIVEN MR #1 在 GitLab 已被 merge
WHEN POST /api/v1/merge-requests/{id}/sync-status
THEN response status = 200
AND status = "MERGED"

### Error Handling

#### Scenario: 重複建立 MR
GIVEN codegen #1 已經建立過 MR
WHEN POST /api/v1/merge-requests with { "codegen_id": "#1", "created_by": "lynn.yang" }
THEN response status = 409
AND response body code = "DUPLICATE"

#### Scenario: GitLab API 失敗
GIVEN GitLab API 不可達
WHEN POST /api/v1/merge-requests with { "codegen_id": "#1", "created_by": "lynn.yang" }
THEN response status = 502
AND response body code = "GITLAB_ERROR"
AND 系統中不會建立 MR 記錄（rollback）

#### Scenario: codegen 不存在
WHEN POST /api/v1/merge-requests with { "codegen_id": "nonexistent", "created_by": "lynn.yang" }
THEN response status = 404
AND response body code = "NOT_FOUND"

### Edge Cases

#### Scenario: MR 包含多個檔案的變更
GIVEN codegen #1 包含 pro.ts 和 std.ts 兩個檔案的修改
WHEN 建立 MR
THEN MR 的 commit 包含兩個檔案的修改
AND MR description 列出所有變更

#### Scenario: branch name 衝突
GIVEN GitLab 上已存在 sync-model/2026-04-02-abc123 branch
WHEN 系統嘗試建立同名 branch
THEN 自動產生不同的 hash 重試
