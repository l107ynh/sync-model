## 區域說明

### 1. Header Bar
- 左側：Logo「Sync Model」
- 右側：使用者頭像（未來 Sprint）

### 2. 快速統計列（Stats Row）
四個統計卡片，水平排列：

| 統計 | Icon | 值來源 |
|------|------|--------|
| 版本數 | `Tag` | `GET /api/v1/versions` pagination.total |
| Model 總數 | `Boxes` | 所有版本的 model_components_count 總和 |
| 元件數 | `Puzzle` | 最新版本的 model_components_count |
| 環境數 | `Globe` | `GET /api/v1/versions/:id/environments` data.length |

### 3. 版本卡片列表
- 響應式 grid：xl=4 欄、lg=3 欄、md=2 欄、sm=1 欄
- 按 `created_at` 倒序排列
- 最新版本標示 ★ 並有 `ring-2 ring-primary` 邊框

### 版本卡片結構

```
┌──────────────────────────┐
│ ★ Version Name     Badge │  ← Badge 顯示 "latest" (最新版)
│                          │
│ Description text...      │  ← 1-2 行描述
│                          │
│ 📦 54 models             │  ← model_components_count
│ 📅 2026-03-15            │  ← created_at 格式化
│                          │
│ [查看設定 →]             │  ← Link to /versions/:id
└──────────────────────────┘
```

## 資料流

```
Page Load
  ├→ GET /api/v1/versions → 版本列表
  └→ GET /api/v1/versions/:latestId/environments → 環境數統計
```
