# Compare 頁面規格（版本比較）

## 路由
`/compare`

## 概述
版本比較頁面，讓使用者選擇兩個版本進行設定差異比較。顯示摘要統計（新增/刪除/修改/未變更）和詳細差異列表。

## 使用元件

| 元件 | 用途 | 來源 |
|------|------|------|
| `SidebarNav` | 左側導航 | `design/components/sidebar-nav.md` |
| `VersionCompare` | 版本選擇 + 比較邏輯 | `design/components/version-compare.md` |
| `DiffViewer` | 欄位級 diff 顯示 | `design/components/diff-viewer.md` |
| `ModelTypeBadge` | Model type 標記 | `design/components/model-type-badge.md` |

## 差異列表分組

差異列表按 `change_type` 分組，每組有 Section header：

| Section | 標題 | 顏色 | 排序 |
|---------|------|------|------|
| Modified | `Modified (N)` | amber | 第一組 |
| Added | `Added (N)` | green | 第二組 |
| Removed | `Removed (N)` | red | 第三組 |

每張卡片顯示：
- Model name (font-mono)
- Model type badge
- Environment badge
- Edition badge
- 展開：欄位級 diff（使用 DiffViewer inline mode）

## 狀態

| 狀態 | 條件 | 呈現 |
|------|------|------|
| Initial | 尚未選擇版本或尚未按比較 | 空白區域 + 提示文字 "選擇兩個版本後按「比較」" |
| Loading | API 請求中 | Skeleton 摘要卡片 + Skeleton 列表 |
| No Diff | changes.length === 0 | "兩個版本的設定完全相同" |
| Loaded | changes.length > 0 | 摘要卡片 + 差異列表 |
| Error | API 錯誤 | 錯誤提示（e.g. "版本不存在"）+ 重試 |

## 互動行為

1. **選擇版本** -> 更新 state（不自動比較）
2. **交換按鈕** -> swap Version A / B
3. **按「比較」** -> fetch API -> 顯示結果
4. **點擊摘要卡片** -> smooth scroll 到對應 section
5. **展開 diff** -> Collapsible 展開欄位級差異
6. **篩選 Environment / Edition** -> 作為 API query params

## 響應式

| 斷點 | 側邊欄 | 選擇器 | 摘要卡片 | 差異列表 |
|------|--------|--------|---------|---------|
| < 768px | 隱藏 | 堆疊（A 在上 B 在下） | 2x2 grid | 全寬卡片 |
| 768-1023px | 固定 | 水平排列 | 4 column | 正常 |
| >= 1024px | 固定 | 水平排列，最大 800px | 4 column | 正常 |
